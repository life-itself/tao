# How we work (with AI)

We organise our shared work as text files in a few shared folders (repos), and we do most of it by talking to an AI that reads and updates those files for us. This page is the path through it, in order. It is growing, and over time it will replace [[getting-stuff-done|Getting Stuff Done]].

## The path

1. **[Post-its and filing cabinets](https://wayintoai.com/use/knowledge-work/concepts)** (about 12 minutes). The picture behind everything: sheets, folders, cabinets, post-its and pointers, and how they map onto digital tools and AI. Part 1 matters most; skim Part 2.
2. **[Our office](https://planning.lifeitself.org/guides/our-office)** (5 minutes). The same picture applied to Life Itself: which repo holds what, where tasks live, and one project traced end to end.
3. **[AI is the interface](https://wayintoai.com/use/knowledge-work/how-to-use-ai)** (15 minutes). Why we stay in the conversation with the AI instead of opening apps, and the everyday loop: what's on this week, turning a mess into a plan, updating progress, handing work on. Read the opening and Chapter 1.
4. **[Set up your computer (with AI)](onboarding#set-up-your-computer-with-ai)** (30 minutes, hands on). One prompt that gets Claude to set up git, GitHub and our task board on your laptop. You need to be in the `life-itself` GitHub organisation first.
5. **[Beads](https://planning.lifeitself.org/guides/beads)** (reference). The task board your AI reads and writes. Read it once you've used it a little.

## Where things live

- **Tao** (this site): who we are and how we work.
- **[Planning](https://planning.lifeitself.org)**: what we're doing now. Initiatives, projects, people, weekly plans and the task board.
- **Each team's repo** (podcast, community and so on): that team's working papers.

Most repos are private, so some links only open once you are in the GitHub organisation.
